# Prime Launcher

Prime Launcher is an open-source Android home-screen launcher focused on speed, deep customization and a clean architecture.

## Roadmap

The first milestone provides a real HOME activity, an installed-app drawer, app launching, a dock/workspace foundation, and settings. Planned milestones add persistent drag-and-drop workspace pages, folders, Android widgets, icon packs, gestures/actions, notification badges, backup/restore, and external search actions such as Quick Search.

## Development

- Kotlin
- Android 8.0+ (minSdk 26)
- Jetpack Compose for settings and drawer UI
- Native Android launcher APIs where required
- Package: `app.primelauncher`

This project is an independent implementation and does not contain Nova Launcher source code or assets.
